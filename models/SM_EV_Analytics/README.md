# Historical semantic model export

This folder preserves the service-exported baseline with six tables, five
relationships and 12 core measures. It is a snapshot, not the current model
for the redesigned report and not a separate Fabric item.

The maintained 29-measure model (12 core plus 17 narrative measures) is in
[`SM_EV_Analytics.SemanticModel/definition`](../../SM_EV_Analytics.SemanticModel/definition).
Use that model together with `RPT_EV_Analytics.Report` for current releases.
Do not overwrite this historical export merely to match a new report design.
See the [semantic model guide](../../docs/architecture/semantic_model.md).
